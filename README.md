## 🛠️ Tech Stack

- Web: HTML + JS + [pdf-lib](https://pdf-lib.js.org/) / [PDF.js](https://mozilla.github.io/pdf.js/)
- Desktop: Python local-server shell packaged with PyInstaller

## 📦 Build from Source

```bash
# Web version
#   The entire tool is a single index.html + app.js — just open it in a browser,
#   or serve this repo with any static file server.

# Portable Windows app
pip install pyinstaller
pyinstaller shell.spec
```

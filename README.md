# PDF To JPG

> Free PDF To JPG tool by [GitVaults](https://gitvaults.com). Runs 100% locally — your files never leave your device.

## ✨ Features

- Full pdf to jpg processing in your browser or as a portable Windows app
- 100% local: files are never uploaded to any server
- Free, no registration, no watermarks
- Open source (MIT License)

## 🚀 Try It Online

**[GitVaults PDF To JPG](https://gitvaults.com/tools/pdf-to-jpg/)**

Use it instantly in your browser, no installation required.

## 💾 Portable Version (Windows)

**[Download the portable app](https://gitvaults.com/download/pdf-to-jpg/)**

- No installation, no registry changes, no leftovers
- Works on Windows 10 / 11 (64-bit)
- Size: ~8–15 MB

## 🛠️ Tech Stack

- Web: HTML + JS + [pdf-lib](https://pdf-lib.js.org/) / [PDF.js](https://mozilla.github.io/pdf.js/)
- Desktop: Python local-server shell packaged with PyInstaller

## 📦 Build from Source

```bash
# Web version
#   The entire tool is a single index.html + app.js — just open it in a browser,
#   or serve this repo with any static file server.

# Portable Windows app
pip install pyinstaller
pyinstaller shell.spec
```
